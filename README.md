# 🎓 Student Enrollment Form

✨ A clean and responsive *Student Enrollment Form* built with *React, Formik, and Yup*.  
This project focuses on creating a user-friendly registration experience with proper form validation. 📝💙

## 🌟 Features

- 🎓 Student Enrollment Form
- 👤 Full Name validation
- 🎂 Date of Birth validation
- 👨‍👩‍👧 Father & Mother Name fields
- ⚧️ Gender selection
- 📱 Responsive User Interface
- ⚡ Form handling using Formik
- 🛡️ Form validation using Yup
- ❌ Displays validation messages for invalid inputs
- ✨ Clean and simple UI

## 🛠️ Technologies Used

- ⚛️ React.js
- 📝 Formik
- 🛡️ Yup
- 🎨 HTML5
- 💅 CSS3
- ⚡ Vite
- 💻 JavaScript
